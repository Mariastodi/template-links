# Linktree Style - Maria Beatriz 

Este é um projeto de página de links pessoal, desenvolvido com foco em **Design System da Apple** e Glassmorphism. A página foi otimizada para ser responsiva, acessível e garantir que ícones de redes sociais carreguem perfeitamente em dispositivos móveis.

## Tecnologias Utilizadas

* **HTML5**: Estrutura semântica.
* **CSS3**: Estilização avançada com Flexbox e Efeito Glass.
* **Font Awesome**: Ícones de redes sociais.
* **Google Fonts**: Tipografia moderna e limpa, inspirada no design da Apple.

## Funcionalidades

* **Design Responsivo**: Adaptado para Desktop, Tablets e Mobile.
* **Spec-Driven Development**: Inspirado nos conceitos de documentação e contexto estruturado.
* **Efeito Glassmorphism**: Uso de `backdrop-filter` para transparência elegante.
* **Acessibilidade**: Links com targets apropriados e nomes descritivos.

## Visualização Mobile

O projeto resolve problemas comuns de renderização de ícones em dispositivos móveis através do uso de CDNs estáveis e alinhamento via Flexbox, garantindo que a experiência do usuário seja consistente em iOS e Android.
